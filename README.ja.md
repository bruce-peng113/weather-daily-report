# 每日天気アラート日報（Weather Daily Report）

アパレル・EC 運用向けの多都市天気日報ダッシュボード。天気データを自動取得し、可視化ダッシュボードを生成して、画像を飛書（Feishu / Lark）グループにプッシュします。

> ⚠️ **現在のバージョンは中国本土向けです**：データソースは高徳天気（中国の都市のみ）、地図は中国地図、プッシュ先は飛書です。海外・グローバル版は計画中で、まだ提供していません。

> 背景：洋服を販売していると、毎日天気をチェックして仕入れや販促の判断をしなければなりません。このツールは「天気チェック」の作業をすべて自動化します——毎朝、36 都市以上の当日レポートを自動生成し、そのまま飛書グループに配信。全国の寒暖分布・気温が下がる都市・服装のアドバイスを一目で把握できます。

## 主な機能

- 🌡️ **多都市のリアルタイム天気**：高徳（Amap）天気 API。36 以上の主要都市に対応（地域ごとにカスタマイズ可能）
- 📊 **ビジュアルダッシュボード**：中国気象局カラースケール（青＝寒い → 赤＝暑い）、天気絵文字アイコン、今後 4 日間の気温トレンド折れ線
- 🗺️ **中国地図ヒートマップ**：省平均気温の塗り分け + 省境・国境・九段線の破線表示（Alibaba DataV 公式 GeoJSON）
- 📅 **前年同期との比較**：Open-Meteo の無料履歴 API で今年が寒いか暑いかを判断
- 📱 **飛書への画像プッシュ**：ダッシュボードを自動スクリーンショットし、飛書ボット経由でグループに画像を送信
- ⏰ **スケジュール自動化**：任意のスケジューラーと組み合わせて、毎朝決まった時間に自動実行

## クイックスタート

### 1. 認証情報の設定

```bash
cp .env.example .env
# .env を編集し、高徳のキーと飛書の認証情報を入力
```

### 2. 依存関係のインストール

`pip` によるインストールは不要です。Python 標準ライブラリと Chrome（スクリーンショット用）のみで動作します。

### 3. ダッシュボードの生成

```bash
python3 gen_weather.py      # 天気データを取得して data.json を生成
open index.html             # ブラウザでダッシュボードを開く
```

### 4. 飛書へのプッシュ

```bash
python3 push_image.py       # スクリーンショット + 飛書グループへ画像送信
```

## 申請が必要な 2 つの認証情報

| 認証情報 | 申請先 |
|----------|--------|
| 高徳天気キー | https://lbs.amap.com/ → コンソール → アプリ管理 → アプリ作成 → キー追加（「Web サービス」を選択） |
| 飛書ボット | 飛書オープンプラットフォーム → 自社アプリ → 「ボット」機能を追加 → 権限 im:message + im:resource + im:chat を有効化 |

## ディレクトリ構成

```
weather-dashboard/
├── index.html          # ダッシュボード（データとレイアウトを分離）
├── gen_weather.py      # データ取得と data.json の生成
├── push_image.py       # スクリーンショット + 飛書へ画像プッシュ
├── push_feishu.py      # 旧版テキストプッシュ（参考用）
├── china.json          # 中国地図 GeoJSON
├── .env.example        # 認証情報テンプレート
└── .gitignore
```

## カスタマイズ

- **都市リスト**：`gen_weather.py` 先頭の `REGIONS` を編集（都市名 + adcode）
- **服装アドバイス**：`gen_weather.py` 先頭の `CLOTHING` 辞書を編集
- **レイアウト / 配色**：`index.html` 内の `tempColor()`、`weatherIcon()`、`renderMap()` を編集

## よくある質問

- **高徳のレート制限**：無料キーには QPS 制限があります。スクリプトにリトライ + 待機処理を内蔵済みです
- **スクリーンショットが白くなる**：Chrome headless でローカルファイルを開くには `--allow-file-access-from-files` が必要です（既に対応済み）
- **飛書で画像が送れない**：グループの「カスタムボット webhook」では画像を送れません。「自社アプリ + im/v1/images アップロード」を使う必要があります
