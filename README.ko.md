# 매일 날씨 알림 일보（Weather Daily Report）

의류 · 이커머스 운영을 위한 다중 도시 날씨 대시보드입니다. 날씨 데이터를 자동으로 가져와 시각화 대시보드를 생성하고, 이미지를 페이슈(Feishu/Lark) 그룹으로 푸시합니다.

> 배경: 옷을 팔다 보면 매일 날씨를 확인해 재고 확보와 판촉 품목을 정해야 합니다. 이 도구는 "날씨 확인"이라는 일을 전부 자동화합니다——매일 아침 36개 이상 도시의 당일 리포트를 자동 생성해 페이슈 그룹으로 바로 전송하므로, 전국 한파/폭염 분포, 기온이 내려가는 도시, 옷차림 조언을 한눈에 볼 수 있습니다.

## 주요 기능

- 🌡️ **다중 도시 실시간 날씨**: 고덕(Amap) 날씨 API. 36개 이상의 핵심 도시 지원(지역별 커스터마이즈 가능)
- 📊 **시각화 대시보드**: 중국기상국 컬러 스케일(파랑=추움 → 빨강=더움), 날씨 이모지 아이콘, 향후 4일 기온 추세 꺾은선
- 🗺️ **중국 지도 히트맵**: 성 평균 기온 색칠 + 성 경계·국경·구단선 점선 표시(Alibaba DataV 공식 GeoJSON)
- 📅 **작년 동기 비교**: Open-Meteo 무료 이력 API로 올해가 추운지 더운지 판단
- 📱 **페이슈 이미지 푸시**: 대시보드를 자동 캡처해 페이슈 봇으로 그룹에 이미지 전송
- ⏰ **스케줄 자동화**: 임의의 스케줄러와 연동해 매일 아침 정해진 시간에 자동 실행

## 빠른 시작

### 1. 인증 정보 설정

```bash
cp .env.example .env
# .env 를 편집해 고덕 키와 페이슈 인증 정보를 입력하세요
```

### 2. 의존성 설치

`pip` 설치가 필요 없습니다. Python 표준 라이브러리와 Chrome(캡처용)만 있으면 됩니다.

### 3. 대시보드 생성

```bash
python3 gen_weather.py      # 날씨 데이터를 가져와 data.json 생성
open index.html             # 브라우저에서 대시보드 열기
```

### 4. 페이슈로 푸시

```bash
python3 push_image.py       # 캡처 + 페이슈 그룹에 이미지 전송
```

## 신청해야 하는 두 가지 인증 정보

| 인증 정보 | 신청처 |
|-----------|--------|
| 고덕 날씨 키 | https://lbs.amap.com/ → 콘솔 → 앱 관리 → 앱 생성 → 키 추가("웹 서비스" 선택) |
| 페이슈 봇 | 페이슈 오픈 플랫폼 → 자체 앱 → "봇" 기능 추가 → 권한 im:message + im:resource + im:chat 활성화 |

## 디렉터리 구조

```
weather-dashboard/
├── index.html          # 대시보드(데이터와 레이아웃 분리)
├── gen_weather.py      # 데이터 가져오기 및 data.json 생성
├── push_image.py       # 캡처 + 페이슈에 이미지 푸시
├── push_feishu.py      # 구버전 텍스트 푸시(참고용)
├── china.json          # 중국 지도 GeoJSON
├── .env.example        # 인증 정보 템플릿
└── .gitignore
```

## 커스터마이즈

- **도시 목록**: `gen_weather.py` 상단의 `REGIONS` 편집(도시명 + adcode)
- **옷차림 조언**: `gen_weather.py` 상단의 `CLOTHING` 딕셔너리 편집
- **레이아웃 / 색상**: `index.html`의 `tempColor()`, `weatherIcon()`, `renderMap()` 편집

## 자주 묻는 질문

- **고덕 속도 제한**: 무료 키에는 QPS 제한이 있습니다. 스크립트에 재시도 + 대기가 내장되어 있습니다
- **캡처가 흰 화면으로 나옴**: Chrome headless로 로컬 파일을 열려면 `--allow-file-access-from-files`가 필요합니다(이미 처리됨)
- **페이슈에서 이미지 전송 불가**: 그룹의 "커스텀 봇 webhook"으로는 이미지를 보낼 수 없습니다. "자체 앱 + im/v1/images 업로드"를 사용해야 합니다
